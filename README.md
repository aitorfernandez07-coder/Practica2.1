# Practica2.1
Practica para la asignatura de Acceso a Datos.

Ejercicio:
En esta práctica vamos a hacer un ejercicio sobre lectura y escritura de ficheros. Vamos a realizar un programa que, mediante la consola, permita: crear un fichero nuevo, abrir un fichero existente, añadir, modificar o eliminar un registro del fichero y visualizar un conjunto determinado de registros.
Todas estas opciones, se presentarán al usuario a través de un menú como el que se muestra a continuación:
1. Crear un nuevo fichero con el nombre que el usuario le pase por consola.
2. Añadir registros en el fichero.
3. Eliminar todos los registros del fichero.
4. Eliminar el fichero.
5. Visualizar los registros.
6. Cerrar la aplicación.
La forma de hacerlo es totalmente libre, podéis usar la programación orientada a objetos o hacer simples scripts.

## Uso del programa

Al ejecutar la aplicación, aparece un menú para crear ficheros, añadir registros, vaciar o eliminar un fichero y visualizar sus registros. Los ficheros se guardan en la carpeta `Datos` y cada registro ocupa una línea.

Cuando el programa solicite el nombre del fichero, se debe escribir sin la extensión `.txt`. Por ejemplo, al indicar `clientes`, se utilizará `Datos/clientes.txt`.
